# SWEENLAB SCRIPTS container notes

In Proxmox, select a container, open its Summary notes editor, and paste the block below. Change the heading and add container details or a service link as needed. The image uses a public, commit-pinned GitHub URL so it can load in the Proxmox browser UI.

```html
<div align="center">
  <img src="https://raw.githubusercontent.com/SweenLab/sweenlab-scripts/4f0038a7560099e0ccf3aaaa04338bb2c51cfa2d/assets/branding/sweenlab-scripts-banner.png" alt="SWEENLAB SCRIPTS" width="480">
  <h2>Debian LXC</h2>
  <p>Created with SWEENLAB SCRIPTS</p>
  <p>
    <a href="https://github.com/SweenLab/sweenlab-scripts">GitHub</a> ·
    <a href="https://github.com/SweenLab/sweenlab-scripts/blob/main/docs/proxmox-debian-lxc-create.md">Guide</a> ·
    <a href="https://github.com/SweenLab/sweenlab-scripts/releases">Releases</a>
  </p>
</div>
```

The banner and crest are available under [assets/branding](../assets/branding/). This template is optional; the wizard does not overwrite existing container notes.
